An original, offline arcade flight through a moonlit garden. Gather six drifting pollen lights, weave past thorn sprites, and carry the moonseed to the open bloom before dawn.

## Run it

~~~sh
node serve.ts
~~~

Open [http://localhost:8080](http://localhost:8080) in a desktop browser.

## Controls

- **WASD** or **arrow keys** to glide
- **Space** to dash through danger
- **P** or **Escape** to pause

Made with canvas and original code-drawn art. No network access or external assets are needed.
